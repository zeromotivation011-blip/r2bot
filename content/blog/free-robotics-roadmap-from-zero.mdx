# Free Robotics Roadmap: How to Learn Robotics from Zero

Robotics mixes electronics, mechanics and software. That sounds scary, but you can learn it in layers. This roadmap shows an order that works, using mostly free material.

## Stage 0: Understand what a robot is (1 week)

Read [How Do Robots Work?](/blog/how-do-robots-work). A robot senses, decides and acts. If you remember that loop, everything else is detail.

## Stage 1: Electronics basics (2 to 3 weeks)

Learn voltage, current, resistance, and how a breadboard works. Build an LED circuit. Use free simulators if you have no kit yet; try the [R2BOT simulator](/schools/simulate).

**Skip:** deep circuit theory for now.

## Stage 2: Programming a microcontroller (3 to 4 weeks)

Get an Arduino. Learn to read a button, blink an LED, and read a distance sensor. Not sure which board? See [Arduino vs Raspberry Pi](/blog/arduino-vs-raspberry-pi-india-students).

## Stage 3: Your first moving robot (3 to 4 weeks)

Build the [obstacle-avoiding robot](/blog/first-robot-project-india-step-by-step). Understanding comes from wiring, debugging and seeing it fail.

## Stage 4: Control and feedback (3 to 4 weeks)

Learn why robots need feedback and what [PID control](/blog/pid-controller-explained-simply) does. Build a line follower.

## Stage 5: Pick a direction

- **Software and AI:** Python, OpenCV, [ROS 2](/blog/ros-vs-ros2-which-to-learn), [machine learning for robots](/blog/how-robots-learn-machine-learning-and-reinforcement-learning).
- **Embedded:** C/C++, microcontroller peripherals, motor control.
- **Mechanical:** CAD, 3D printing, robot arms.
- **Perception and navigation:** [cameras, lidar and radar](/blog/lidar-vs-radar-vs-camera-for-robots), [SLAM](/blog/what-is-slam-in-plain-words).

## Stage 6: Show your work

Put code on GitHub with a clear README and a short video. Join a club or competition. See [how to join a robotics club](/blog/iit-robotics-clubs-guide) and [robotics careers](/blog/robotics-career-india-salary-jobs-2025).

## A study habit that works

- Build something small every week.
- Write down every bug you fix. You will meet it again.
- Read one Atlas concept each day.

## What goes wrong

Learners often jump to advanced topics such as AI or humanoids before they have built a basic robot. Without hands-on experience, you cannot tell whether a tutorial is correct or why your code fails.

## Frequently asked questions

**How long does it take?**
About three months to build a useful first robot at a few hours a week. Real depth takes years.

**Do I need to be good at math?**
Not at first. Math matters later for control, geometry and machine learning.

**Is it free?**
Learning material is free. A small kit costs money, but a simulator lets you start with nothing.
